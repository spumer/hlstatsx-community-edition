# Render-snapshot page list for FEAT-0027-PLAN §6.3 (render-snapshot parity gate).
#
# One relative URL (path + query string, no scheme/host -- render-snapshot.sh
# prepends BASE_URL) per line. Blank lines and lines starting with '#' are
# ignored. An inline "# comment" after a URL documents which file(s) it
# exercises; it is not parsed, purely for maintainers reading this file.
#
# Placeholder values (game=l4d2, player=1, clan=1, weapon=1, map=1, action=1,
# award=1, rank=1, ribbon=1, role=1, flag=US) assume a seed database has at
# least one row for each entity under game code "l4d2". If your seed uses a
# different game code or these IDs don't resolve, the pages will still
# render (empty tables / "no such X" error states) -- that's a valid parity
# target too, since error() also resolves through the i18n facade. For a
# richer diff (real table rows, not just headers), point these at IDs that
# actually exist in your seed data and adjust the game code to match.
#
# Sub-pages of claninfo.php/playerinfo.php/awards.php are only reachable via
# their own AJAX tab dispatch (mode=X&type=ajax&tab=Y), not as a standalone
# mode -- see the routing notes below each family. header.php, footer.php,
# livestats.php, search-class.php, and web/includes/{class_table,functions,
# i18n}.php have no route of their own; they're exercised indirectly by
# every URL below (header/footer wrap every page; livestats.php backs the
# server tables on servers.php/game.php; search-class.php backs search.php).
